# Card grammar — the card types and how a piece is assembled from them

A piece is a deck of cards. Each card is one stage colour, one line or number, one
focal event. The grammar below names the types; the copy deck decides the order.

## 1. Card types

| type | layout | line | focal event | hold |
|---|---|---|---|---|
| Greeting | hero word centred on a Semicircle or plain stage, one swap, one loop accent | "hello!", "hi there" | glyph swap pop | 1.5 s |
| Welcome | statement line, shapes bleeding top and bottom, arrow accent | "welcome to", "you made it" | word land | 1.25 s |
| Countdown | number in a hero shape that morphs per number; number slides | 10, 9, 8 … or 3, 2, 1 | shape morph + number slide | 0.5 s each |
| Announcement | statement or sentence on a stage, one swap, underline accent | "Grab a snack", "Doors open 7 pm" | tracking breathe + swap | 1.5–2 s |
| Question | sentence stepped over 3–4 lines, two swaps, squiggle accent, cream stage | "How will today change tomorrow?" | word land then swaps | 2.5 s |
| Badge row | five to six badges roll in on a blush or cream stage, no line | none, or a single word in one badge | badge roll-in | 1.5 s |
| Badge cluster | four overlapping badges on the ink stage, arrows floating | none | cluster settle | 1.5 s |
| Constellation | 6–10 small shapes joined by curved lines on cream | none, or a single word | constellation drift | 2 s |
| Capsule | a Pill jar filling with small shapes on yellow | none | capsule fill | 1.5 s |
| Thought | a scalloped cloud (Clover8 stretched) holding a shape, small trailing circles | none | scale pop | 1 s |
| Break | statement on blush with a loop accent | "We'll be back soon" | accent draw-on | 1.5 s |
| Return | statement on a saturated stage with shapes bleeding top and bottom | "See you soon!", "Let's go" | word land + arrow | 1.5 s |
| Closer | single word at hero size, every swap resolving back to letters, then plain word | "beautiful", "thank you", the title | swaps resolve | 2.5 s |
| Ident | logo described as cast shapes assembling into a mark | brand name | cluster settle then hold | 2 s |

## 2. Copy rules

- ≤ 7 words per card, sentence case, one idea. A number is a card.
- Prefer verbs and addresses: "Grab a snack", "See you soon", "What will you make?"
- Questions are the emotional peak; give them the longest hold and the cream stage.
- The closer is one word that names the feeling, then resolves to plain type.
- Never two consecutive cards with the same stage colour.

## 3. Deck templates by register

| register | deck |
|---|---|
| Event opener (20–30 s) | Greeting → Welcome → Countdown 3 → Announcement → Badge row → Question → Constellation → Return → Closer |
| Break bumper (10–15 s) | Announcement ("Grab a snack") → Badge cluster → Capsule → Break → Return |
| Launch teaser (15–20 s) | Greeting → Announcement (what) → Countdown 3 → Badge cluster (features as badges) → Question → Ident |
| Milestone / celebration (8–12 s) | Countdown 3 → Hero number card → Announcement ("100 days!") → Badge row → Closer |
| Lyric / quote loop (10–20 s) | Question or statement cards, one line each, alternating stages, swaps on the key words, loop back to the first stage |
| Ident (5–8 s) | Badge cluster → Ident → Closer |

## 4. Assembly rules

- Alternate saturated and neutral stages so the eye rests: blue → cream → orange → blush → green → ink → yellow.
- The countdown is the tempo peak; the question is the emotional peak; the closer is the release.
- Every third card has no words at all. Shapes need room to play.
- The cast must appear at least once each in the first quarter of the piece.
